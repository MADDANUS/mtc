## Rencana Implementasi

### 1. Refactor Generator Excel (RiwayatController.php)
Saat ini fungsi `generateOverhaulExcelNative` dan `generatePreventiveExcelNative` membangun Excel sekaligus langsung melakukan *output* dan mematikan eksekusi skrip (`exit()`).

### 2. Buat Metode Baru `exportExcelAll($departemenSlug)` (RiwayatController.php)

- Menarik seluruh data transaksi yang cocok dengan filter.
- Membuat objek `Spreadsheet` baru.
- Melakukan *loop* per transaksi:
  - Membuat `Worksheet` (sheet) baru.
  - Memanggil `buildOverhaulExcelSheet` atau `buildPreventiveExcelSheet` tergantung jenis transaksinya.
- Menyimpan dan mengeluarkan output 1 file `.xlsx` berisi banyak *sheet*.

### 3. Daftarkan Route (Routes.php)
- Menambahkan route `GET riwayat/export-excel-all/(:segment)` -> `RiwayatController::exportExcelAll/$1`

### 4. Tambahkan Tombol di Tampilan (app/Views/riwayat/index.php)
- Menambahkan link/tombol `Download Full Excel` (misalnya warna biru/hijau) di samping tombol `Download PDF`.
- Menyesuaikan parameter filter ke dalam query string URL.
